## Ramas y publicación / Branches and releases

- `dev`: trabajo continuo / ongoing work.
- `main`: solo versiones estables publicadas, con tag `vX.Y.Z` / stable published versions only, tagged `vX.Y.Z`.
- Publicación en CurseForge con BigWigs packager y GitHub Action al crear un tag (alpha, beta o release según madurez). / CurseForge release via BigWigs packager and a GitHub Action on tag (alpha, beta or release by maturity).
